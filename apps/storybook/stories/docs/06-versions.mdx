# 更新與版本

目前版本：**{pkg.version}**

## 更新

```bash
npm install @coss-app/ui@latest
```

更新後跑一次 `npm run build`，並檢查主要頁面的畫面。

## 版本規則

- 目前是 0.x：minor 版本（0.x.0）可能包含破壞性變更，CHANGELOG 會標明「破壞性」並說明怎麼改；patch 版本（0.0.x）只修 bug。
- 1.0 之後照標準 semver，只有 major 版本會有破壞性變更。
- 建議在 `package.json` 寫 `"@coss-app/ui": "~0.2.0"`，只自動更新 patch；要升 minor 時，先看完 CHANGELOG 再手動升。
