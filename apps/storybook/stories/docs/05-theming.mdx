# 主題與深色模式

所有顏色都是 CSS 變數（design token），定義在 `@coss-app/ui/globals.css`。完整清單與色塊見 Foundations / Colors，字級見 Foundations / Typography。

這些色彩 token 已經全部內建在套件裡，import globals.css 就能用，專案不需要新增。

## 在 Tailwind class 裡用 token

| 用途 | class |
| --- | --- |
| App 底色／面板 | `bg-background`／`bg-card` |
| 內文／次要文字／placeholder | `text-foreground`／`text-muted-foreground`／`text-placeholder` |
| 主要動作（品牌綠） | `bg-primary text-primary-foreground` |
| 資訊（連結、選中） | `text-info`、`bg-info`、`bg-info-muted` |
| 成功／警示／錯誤淡底 | `bg-success-muted text-success-foreground`、`bg-warning-muted text-warning`、`bg-destructive-muted text-destructive-foreground` |
| 分隔線 | `border-border` |
| 浮層陰影 | `shadow-menu`、`shadow-picker`、`shadow-tab`、`shadow-float` |

底色與字色要成對使用：綠底配白字，淡底配同色系的深色字。

## 深色模式

在 `<html>` 加上 `class="dark"` 就會切換，所有色彩變數換成深色值。Next.js 用 `next-themes` 控制：

```tsx
<ThemeProvider attribute="class" defaultTheme="system" enableSystem>
```

Tailwind 的 `dark:` 前綴也跟著 `.dark` class 走。

## 專案要微調顏色

在 import 之後覆寫變數就好，不用改套件：

```css
@import "@coss-app/ui/globals.css";

:root {
  --radius: 0.5rem; /* 全站圓角基準 */
}
.dark {
  --background: #0b0e1e;
}
```

不建議改 `--primary` 等品牌色，會偏離公司設計規範。需要新的顏色時，請到 coss-app/ui 提出，統一加進套件。

## 減少動態

使用者在系統開啟「減少動態」時，彈窗、抽屜和 Toast 只保留淡入淡出，不滑動也不縮放。globals.css 已經處理好，專案不用另外設定。
