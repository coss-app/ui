# @coss-app/ui

coss 公司通用 UI 組件庫，共 65 個組件，以 [shadcn/ui](https://ui.shadcn.com)（Base UI 版）和 Tailwind CSS v4 為基礎，套用公司設計規範「靛藍＋品牌綠」。

目前版本：**{pkg.version}**　·　原始碼：[github.com/coss-app/ui](https://github.com/coss-app/ui)　·　套件：[npmjs.com/package/@coss-app/ui](https://www.npmjs.com/package/@coss-app/ui)

## 30 秒開始

不用 token、不用 `.npmrc`，直接安裝：

```bash
# 1. 安裝
npm install @coss-app/ui
```

```css
/* 2. 全域 CSS（取代 @import "tailwindcss"） */
@import "@coss-app/ui/globals.css";
```

```tsx
// 3. 使用
import { Button } from "@coss-app/ui/components/button";

export function CreateTicket() {
  return <Button>建立工單</Button>;
}
```

## 設計原則（摘要）

- 綠色只給主要動作與目前位置：主要按鈕、選中的側邊選單、進度。一個畫面只放一個主要按鈕。
- 資訊用藍色：連結、勾選、日期選中、處理中狀態都用資訊藍。
- 文字不用純黑，用深靛藍；灰階全部帶藍紫調。
- 幾乎不用陰影，靠底色與白色面板的明暗差分層；只有浮層（下拉、彈窗、Toast）有淡陰影。
- 主要動作用膠囊形，容器 10px 圓角，彈窗 25px。

完整規範見 repo 內的 `DESIGN.md`。
