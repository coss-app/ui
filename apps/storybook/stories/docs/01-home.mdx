# @coss-app/ui

coss 公司通用 UI 組件庫：65 個組件，基於 [shadcn/ui](https://ui.shadcn.com)（Base UI 版）＋ Tailwind CSS v4，套用公司設計規範「靛藍＋品牌綠」。

目前版本：**{pkg.version}**　·　原始碼：[github.com/coss-app/ui](https://github.com/coss-app/ui)（需 coss-app 成員權限）

## 30 秒開始

```bash
# 1. 專案根目錄 .npmrc（token 取得方式見「安裝與權限」）
echo '@coss-app:registry=https://npm.pkg.github.com' >> .npmrc
echo '//npm.pkg.github.com/:_authToken=${NODE_AUTH_TOKEN}' >> .npmrc

# 2. 安裝
npm install @coss-app/ui
```

```css
/* 3. 全域 CSS（取代 @import "tailwindcss"） */
@import "@coss-app/ui/globals.css";
```

```tsx
// 4. 使用
import { Button } from "@coss-app/ui/components/button";

export function CreateTicket() {
  return <Button>建立工單</Button>;
}
```

## 設計原則（摘要）

- **綠色只給主要動作與目前位置**：主要按鈕、選中的側邊選單、進度。一個畫面只放一個主要按鈕。
- **資訊用藍色**：連結、勾選、日期選中、處理中狀態都是資訊藍。
- **文字不用純黑**：深靛藍；灰階全部帶藍紫調。
- **幾乎不用陰影**：靠「底色 vs. 白色面板」分層；只有浮層（下拉、彈窗、Toast）有淡陰影。
- **主要動作是膠囊形**，容器 10px 圓角，彈窗 25px。

完整規範見 repo 內的 `DESIGN.md`。
